# Beijing building footprints

Building footprint geometry for Beijing is not redistributed owing to data privacy and proprietary restrictions. This folder provides footprint snapshots (`Beijing_building_footprints_overview.png`, `Beijing_building_footprints_detail.png`) and a 20-building sample of the attribute fields (`Beijing_building_attributes_sample.csv`). The building attribute tables used by the code are in `code/data/supporting_data/`. The full footprint data are available from the corresponding authors on reasonable request.
